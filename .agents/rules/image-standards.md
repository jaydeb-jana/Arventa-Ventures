# Image Standards & Rules

- **Format:** All website images must be in `.webp` format (excluding SVG icons and logos).
- **Quality & Performance:** Every image must be highly optimized WebP format stored locally in `public/images/`.
- **Branding:** Visuals must feature Arventa Ventures branding and electric orange (`#f97316`) aesthetic.
- **Cultural Authenticity:** Portray Indian professionals in modern workplace environments.
- **No Stock Media:** Never use Unsplash, Picsum, or generic stock media.
