# Arventa-Ventures

Official website and digital marketing platform for **Arventa Ventures** — Premier Digital Marketing Agency delivering high-ROI SEO, Meta Ads, Google Ads, and Performance Marketing.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + Framer Motion
- **Routing:** React Router v7
- **Sitemap & SEO:** Multi-language SEO & Automated Sitemap Generator

## Getting Started

### Install Dependencies
```bash
bun install
# or
npm install
```

### Run Locally
```bash
bun run dev
# or
npm run dev
```

### Production Build
```bash
bun run build
# or
npm run build
```
